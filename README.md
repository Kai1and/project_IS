# АИС «Доставка еды»

Репозиторий проекта внедрения объединяет требования, проверяемую модель заказа и правила передачи изменений на испытания. Центральный сценарий — одновременные действия двух операторов и отказ SMS после сохранения заказа. Код представляет учебную модель в памяти; промышленному серверу потребуются транзакции и проверка версии в БД.

## Структура папок

```text
project_IS/
├── docs/
│   └── requirements.md
├── src/
│   └── order_flow.py
├── tests/
│   └── test_order_flow.py
├── management/
│   └── repository_rules.md
└── README.md
```

## Как запустить и использовать

Нужен Python 3.10 или новее, сторонние пакеты не используются. Из корня репозитория выполнить:

```text
python -B -m unittest discover -s tests -v
```

Пять проверок должны завершиться с результатом `OK`. Требования находятся в `docs/requirements.md`, правила командной работы — в `management/repository_rules.md`. Код не запускает веб-сервер и не отправляет реальные SMS.
